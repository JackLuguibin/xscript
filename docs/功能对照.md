# 功能对照：XScript 与 AScript

这份清单把 AScript 官网（ascript.cn）列出的 Android 功能和 XScript 当前的实现逐项对照，用来决定下一步做什么。

对照依据有两个：

- **AScript 侧**：官网 sitemap（2026-10-01）中的 Android API 文档和服务页面。
- **XScript 侧**：本仓库的代码。

**Python 版本对照**：AScript 4.0.10 的设备端是 Python 3.8（APK 里是 `libpython3.8.so`，`chaquopy/build.json` 写着 `python_version: 3.8`），其官方 VS Code 插件在电脑上要求 Python 3.9–3.13（ascript.cn 文档）；XScript 设备端是 Python 3.10（Chaquopy 17，受 OpenCV 4.5.1 wheel 限制）。为 3.8 / 3.9 写的脚本一般能直接运行；用到 3.11 及以上特性（`tomllib`、`except*` 等）的脚本在设备上不能运行。

AScript 兼容层在 `android/python-runtime/ascript/`，XScript 自有 API 在 `android/python-runtime/xscript/`。

状态说明：

| 标记 | 含义 |
| --- | --- |
| ✅ 已有 | 能用，接口和 AScript 兼容 |
| 🟡 部分 | 能调用，但实现方式不同或功能缩水（见备注） |
| ⛔ 空壳 | 只有接口，调用会报 `NotImplementedError` |
| ❌ 没有 | 接口也没有 |
| 🚫 不做 | 有意不做（原因见备注） |

在「需要？」一列标上你的判断（要 / 不要 / 以后），我按这个排下一批。

**界面、找图找色和桥接的测试（2026-10-20）**：`ascript.android.ui`（WebWindow / Dialog / Loger / Canvas / FloatWindow / ImageWindow）、`ascript.android.screen`（截图各格式、`cache`、Bitmap / base64 / PIL 转换、`Color`、`Colors`、`FindColors`、`CompareColors`、`FindBlock`、`FindImages`、`CodeScanner`、`Eraser`、`Ocr` 各入口、YOLO 路径规则）、`screen.color_tools`、`xscript.android.screen` / `ui` 和 Java 桥接（`xscript/runtime/bridge.py`）有了 71 个测试（`tests/test_ascript_ui.py`、`test_ascript_screen.py`、`test_bridge.py`，共用 `tests/fake_device.py` 假设备）。主机上用手机的库版本通过，arm64 模拟器（`com.xscript.app.perf`，Python 3.10.19、numpy 1.23.3、OpenCV 4.5.1、Pillow 11.0.0）上 71 个全部通过。只测了 Python 一侧：界面操作只检查发给 App 的参数，窗口和悬浮窗的实际显示没有测。

**16KB 页面设备（2026-10-15）**：以前在 Android 17 的 16KB 页面模拟器（`ps16k` 镜像）上 numpy 无法导入（`dlopen failed: library "libopenblas.so" not found`），OpenCV / Pillow 随之不可用。**根因**：Chaquopy 17.0.0（Python 3.10）自带的 numpy 1.23.3、opencv-python 4.5.1.48、Pillow 9.2.0（含 FreeType）的原生库 ELF `PT_LOAD` 对齐只有 4KB（`p_align=0x1000`），16KB 页面的系统拒绝加载（`program alignment (4096) cannot be smaller than system page size (16384)`），先是 `libgfortran` / `libopenblas`，再连带 `_multiarray_umath.so` 一起失败，所以报的是「找不到 libopenblas」。App 自己的 `lib/*.so`、ONNX Runtime 1.22.0 的库和 APK 的 zip 对齐（`zipalign -c -P 16`）本来就是 16KB 对齐的，问题只在 pip 轮子。Chaquopy 已经是 17.0.0，没有可升级的版本；其索引里没有 16KB 对齐的 cp310 numpy / opencv（对齐的只有 numpy 1.26+ 的 cp313 和 Pillow 11 等，而 opencv 4.5.1.48 要求 Python 3.10）。**修复**：在清单的 `<application>` 上加 `android:pageSizeCompat="enabled"`，让系统对本应用启用 16KB 兼容模式（4KB 对齐的库照常加载）。已验证：16KB 模拟器（API 37）上 numpy（core / linalg / fft / random）、OpenCV、Pillow / FreeType、`CvFontLib`、PaddleOCR、YOLO11n（ONNX Runtime）全部通过；4KB 模拟器（API 34）无回归；`scripts/check_16kb.py` 报告 zipalign 通过、应用自带库全部 16KB 对齐，只有轮子里的 56 个原生库仍是 4KB。**代价与限制**：兼容模式下首次加载稍慢、内存占用略高；只验证了 Android 17 模拟器，更早系统（Android 15 的 16KB 开发者选项）对该属性的支持以及真机没有测过；要彻底免掉兼容模式，需要用 NDK 以 `-z max-page-size=16384` 重新编译 numpy / opencv / Pillow（Chaquopy 的 wheel 构建工具链，需 Linux + NDK），或等 Chaquopy 发布对齐的 cp310 轮子。**设备验证（2026-10-14）**：新建 4KB 页面的 API 34 模拟器（`API34_4k`，arm64 google_apis）后，内置 numpy 1.23.3 / OpenCV 4.5.1 可以正常导入，运行时测试 `test_cvfont`（13）、`test_image`（19）、`test_vision`（11）、`test_gp_compat`（10）、`test_vlm_compat`（10）、`test_ml`（17，其中 2 个被测试自身跳过）、`test_ascript_compat`（9）、`test_selector`（16）、`test_resources`（3）在设备上全部通过；其中发现并修复了一个只在 OpenCV 4.5.1 出现的透明模板找图问题（见 CHANGELOG）。4KB 页面的真机没有测过，`test_pip` 以及真实模型推理没有在设备上跑。

## 悬浮窗：AScript 实际做了什么

只记有来源的内容，来源没写的不推测。

**文档**（ascript.cn/docs/android/api/ui/floatwin）：`FloatWindow` “控制 App 小悬浮窗隐藏或展示，还可以定义展示样式”。`show(x=-1, y=-1, dim=1)`：x、y 为正数是固定坐标，小数（`0.2` = 20%）是屏幕比例，`-1` 是最大距离；“x 和 y 为 0 或 -1 时会自动缩边，否则钉在目标位置”；`dim` 是 0–1 的透明度。`hide()` 隐藏。`add_menu(menu_id, menu_ico, menu_click_listener, remove_system=False)` 往悬浮窗的“展开菜单”里加图标按钮，`remove_system=True` 移除系统自带按钮。官网首页把“UI 悬浮窗”列为四种运行模式都支持的能力；“协议启动”页提到 `ascript://stop` 停止运行中的小程序，“云端控制”页有 `app_run` / `app_stop`。

**APK（4.0.10，`ascript_analysis/analysis/`）**：清单声明 `SYSTEM_ALERT_WINDOW`、`SYSTEM_OVERLAY_WINDOW` 和服务 `com.aojoy.airscript.server.floa.FloatService`（没有前台服务类型）；类名里有 `ui.view.miniview.FloatingActionButton` / `FloatingActionMenu`、`MiniViewHelper2`、`ui.floatwin.window.HistoryRunWindow` 等；字符串里有权限提示“需要‘悬浮窗’权限：显示 UI / 显示快捷按键 / HUD / View 树标记等”、“悬浮窗权限不足，无法启动程序”（没有权限时运行被拒）、“悬浮窗权限不足，启动小程序 UI 会报错。打开 App 主页即可前往开启”、“已经开启了悬浮窗权限”和 前往开启 / 前往关闭。

**没有找到来源的**：悬浮窗按钮的具体样子和数量（系统按钮是哪几个）、有没有运行计时、是否只在后台显示、是否自动出现、位置是否记忆。这些来自 XScript 自己的设计，不是对 AScript 的复刻；对照时不要当成 AScript 的行为。
