# 功能对照：XScript 与 AScript

这份清单把 AScript 官网（ascript.cn）列出的 Android 功能和 XScript 当前的实现逐项对照，用来决定下一步做什么。

对照依据有两个：

- **AScript 侧**：官网 sitemap（2026-10-01）中的 Android API 文档和服务页面。
- **XScript 侧**：本仓库的代码。

AScript 兼容层在 `android/python-runtime/ascript/`，XScript 自有 API 在 `android/python-runtime/xscript/`。

状态说明：

| 标记 | 含义 |
| --- | --- |
| ✅ 已有 | 能用，接口和 AScript 兼容 |
| 🟡 部分 | 能调用，但实现方式不同或功能缩水（见备注） |
| ⛔ 空壳 | 只有接口，调用会报 `NotImplementedError` |
| ❌ 没有 | 接口也没有 |
| 🚫 不做 | 有意不做（原因见备注） |

在「需要？」一列标上你的判断（要 / 不要 / 以后），我按这个排下一批。

## 6. 建议的下一批

完整的分阶段策划（包括 AScript 没有、但自建后台需要的功能）见 [路线图.md](路线图.md)。

按「投入小、用户感知大」排序：

1. **短信、定位、传感器**：三个空壳补成真实现。工作量小，兼容 AScript 脚本时不会再报错。
2. **图片字库（cvfont）和 Scheme 链接启动**：都是工作量小的缺口，前者游戏脚本常用，后者方便从网页或 adb 一键运行脚本。
3. **网页 IDE**：不装 VS Code 也能写脚本，降低上手门槛。
4. **AI 识屏（VLM）**：接任意 OpenAI 兼容的视觉模型，解决图色和 OCR 认不出来的情况。之后可以在它上面做 AI 智能体。
5. **外部 APK / JAR 插件加载**：给需要调用第三方 SDK 的脚本用。

其余（HID 硬件、自带输入法、UI 设计器、YOLO 云训练、插件市场）工作量大或依赖硬件 / GPU，建议等有明确需求再做。
