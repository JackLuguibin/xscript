# 十分钟写出第一个脚本

这篇从「手机上已经装好 XScript」开始，带你写一个能找字、点击、打日志的小脚本，再把它放到电脑上管理。只讲最短的路径；各项细节见[使用手册](使用手册.md)。

> 还没安装？见 [快速上手](GETTING_STARTED.md)「构建」和「设备设置」（自己编译 APK、授予通知 / 无障碍 / 悬浮窗权限）。

## 0. 准备（1 分钟）

打开手机上的 XScript，看首页：

![手机 App 首页：运行卡片、开发者地址、配对码和权限](images/phone-home.png)

- **辅助权限管理** 显示「已开启」。点击、找控件都靠它。
- **开发者地址** 显示 `http://<IP>:<端口>/`。如果显示红字「服务未启动」或「端口都被占用」，点一下这一行就会启动或重试。
- **配对码**：电脑第一次连接时要输入它。

## 1. 让电脑连上手机（2 分钟）

任选一种：

- **USB / 模拟器（推荐）**：

  ```bash
  adb forward tcp:9860 tcp:9860          # 端口以「开发者地址」为准
  curl http://127.0.0.1:9860/status      # 返回设备 JSON 就通了
  ```

  之后电脑上的地址是 `http://127.0.0.1:9860/`。模拟器或 adb 重启后要重新 forward，这是最常见的连不上的原因。
- **同一个 Wi-Fi**：直接用「开发者地址」里的 IP，例如 `http://192.168.1.23:9860/`。只在可信网络里这样用。

## 2. 打开脚本 IDE，新建工程（1 分钟）

电脑浏览器打开 `http://127.0.0.1:9860/tools/`（或 `http://<手机IP>:<端口>/tools/`），第一次会要求输入配对码，然后进入 **脚本 IDE**。不用装任何东西。

左侧「工程」点 **新建**，起个名字（字母、数字、下划线，不能以数字开头，可以用中文，例如 `我的第一个脚本`），模板选「空工程」即可（其他模板是找图、OCR、签到等示例，之后可以参考）。新工程里有入口文件 `__init__.py`。

![网页脚本 IDE：左侧工程和文件，中间编辑器，下方运行日志](images/ide-overview.png)

## 3. 写脚本并运行（3 分钟）

把 `__init__.py` 换成：

```python
from xscript.android import action, node, screen

w, h = screen.size()
print("屏幕大小", w, h)

# 找到文字是「设置」的控件并点击；最多等 5 秒
hit = node.Selector().text("设置").click().find(timeout=5)
print("点到了「设置」" if hit else "没找到「设置」，换一个屏幕上能看到的文字试试")

action.sleep(1)
action.back()
```

按 **保存并运行**（F6）。下方 **运行日志** 会实时显示 `print` 的内容；出错时会显示报错行号。手机回到桌面后，屏幕边上的悬浮窗也能停止脚本。

几个要点：

- **不要猜控件**。点击前先确认屏幕上真有这段文字：用顶部 **图色工具** 截一张图看看，或者在 VS Code / PyCharm 里选中一行代码，用「在设备上运行选中代码」单独试。
- 没有文字的界面（游戏、画布）：
  - 用 `screen.find_image(R.img("按钮.png"))` 找图，图片放在工程的 `res/img/` 里，`R` 从 `xscript.android.system` 导入；
  - 或者用 `screen.ocr_find("签到")` 识别文字。
  - `action.click(x, y)` 写死坐标是最后手段：不同分辨率、横竖屏下会点错。
- 长时间循环写在脚本里，在手机上跑，不要从电脑一步步遥控。

## 4. 把工程放到电脑上管理（3 分钟）

在网页 IDE 里写小脚本足够了。工程变大后，建议在电脑上用 Git 管理，用编辑器写：

| 工具 | 上传并运行 | 从手机拉回 | 说明 |
| --- | --- | --- | --- |
| VS Code / Cursor 插件（`ide/vscode-extension`） | Ctrl+Shift+R | 「Pull Project」 | 还支持断点调试、API 补全、运行选中代码 |
| PyCharm 插件（`ide/pycharm-plugin`） | Ctrl+Alt+Shift+R | 「设备工程」标签页 → 拉取；双击打开本地副本 | 底部 XScript 工具窗口看日志，运行选中代码 Ctrl+Alt+Shift+E |
| 桌面端（`desktop/`） | 工程页 | 工程页 | 多设备、云控 |

上传时的几个规则：

- 只上传新增和修改过的文件（按大小和内容摘要比较）。
- `.vscode/.syncignore` 里的规则（gitignore 写法，两个插件共用）决定哪些文件不上传；以点开头的文件、`__pycache__`、`.pyc`、虚拟环境始终不上传。
- **本地删除的文件默认不会从手机上删除**。如果希望手机和本地一致，开启「上传时同步删除」：VS Code 是 `xscript.syncDeletes`，PyCharm 在 设置 → Tools → XScript。每次删除前都会列出文件让你确认；被 `.syncignore` 忽略的文件和入口 `__init__.py` 永远不删。
