# 代理：批发价与结算

状态：草稿计划（docs/plans）。逐阶段实现，每阶段一个或几个小提交，推送到同一个草稿 PR。

## 范围

- 给代理设批发价（按应用 × 卡类型 × 有效期），代理生成卡密时记应付金额；管理员看每个代理的应付 / 已付 / 余额，登记收款（结算），导出对账单 CSV。代理在自己的控制台看到账单。
- 金额用整数分（不用浮点）；所有变更写审计日志；只记账，不接支付通道。
- 不做：在线支付、退款到第三方。

## 依据

- `docs/路线图.md` 代理 / 分销：✅ 已完成的是额度（可生成卡数）、销量趋势和操作日志，没有价格和结算。
- `backend/xscript_server/routes/reseller.py`：只有 `quota/used/left`、`adjust_quota`，没有价格或金额字段。
